# Packet Tracer file

Save the finished lab here as **`hru-campus-lab.pkt`** (File → Save As).

This repository doesn't include a `.pkt` yet. Packet Tracer files can only
be created in Packet Tracer itself, so the file is added once the lab has
been built by following [`../docs/BUILD-GUIDE.md`](../docs/BUILD-GUIDE.md)
and passes [`../docs/VERIFICATION.md`](../docs/VERIFICATION.md).

When you add it, note in the commit message which Packet Tracer version
saved it. Older versions can't always open files saved by newer ones.
